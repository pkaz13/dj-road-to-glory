# MCP (Model Control Protocol) Resources

This directory contains implementations and resources related to MCP (Model Control Protocol). Below there is a curated list of valuable resources and tools for working with MCPs.

- [MCP Directory](https://www.mcpdirectory.io) - Official directory for discovering and integrating MCP tools
