# Monitoring

This folder is dedicated to learning observability and monitoring concepts. It provides a hands-on example of how to collect and visualize telemetry data.

## o11y-logs-and-metrics

Contains a complete Docker Compose-based observability stack showcasing:

- OpenTelemetry Collector configuration
- Prometheus metrics scraping and alerting rules
- Grafana dashboards and data source provisioning
- Loki log aggregation setup
- Tempo distributed tracing configuration
- PostgreSQL initialization and pgAdmin setup
- A sample .NET 8 Products API instrumented with OpenTelemetry

Use this subfolder to explore the flow of logs, metrics, and traces from your application to your monitoring tools.
